## Default Permission

Default permissions for the foxnest-audio plugin

#### This default permission set includes the following:

- `allow-play`
- `allow-pause`
- `allow-resume`
- `allow-seek`
- `allow-skip`
- `allow-set-rate`
- `allow-stop`
- `allow-get-state`
